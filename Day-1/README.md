# Day-1: AI-Powered Bakery Assistant

## Objective
To develop an AI-powered bakery assistant using LangChain and Groq API and explore prompt injection detection.

## Technologies Used
- Python
- LangChain
- Groq API
- GPT-OSS-120B
- Llama Prompt Guard 2

## Implementation
- Configured the Groq API securely.
- Created a system prompt for a home bakery assistant.
- Generated responses to customer queries.
- Tested prompt injection detection using Prompt Guard.

## Installation
`py -m pip install langchain-groq groq`

## Execution
`py task.py`

Enter your Groq API key when prompted.

## Results
- Successfully generated a bakery assistant response.
- Prompt injection detection score: 0.9988957643508911 (99.89%).

## Learning Outcomes
- Prompt engineering
- LLM integration
- System and user prompts
- Prompt injection detection
- Secure API key handling
